# Pacific Gas and Electric Company (PG&E) — Share My Data

> PG&E is the investor-owned electric and natural gas utility for northern and central California.
> Its only public API surface is Share My Data, a production Green Button Connect My Data
> implementation of the NAESB REQ.21 ESPI 1.1 standard, serving customer-authorized energy usage
> data from https://api.pge.com.

## What you need to know before calling anything

- There is **no OpenAPI document**. PG&E publishes its API reference as a PDF table. The only
  machine-readable contract it ships is the ESPI / Share My Data XSD schema bundle.
- **Mutual TLS is mandatory.** Every request to api.pge.com — including the OAuth token endpoint —
  must present a CA-issued TLS 1.2 X.509 client certificate. Self-signed certificates are rejected.
  Without one, every call returns HTTP 400 `"Invalid Certificate"`. No bearer token clears this.
- **You cannot self-serve.** Access requires registration at https://sharemydata.pge.com/, a U.S.
  EIN, eligible standing with the California Public Utilities Commission, and PG&E approval.
- **Scopes are not scope names.** The granted scope is a single ESPI function-block string, e.g.
  `FB=1_3_8_13_14_18_19_31_32_35_37_38_39_40_4_5_10_15_16_46_47;AdditionalScope=...;dataCustodianId=PGE`.
- **Responses are Atom XML**, not JSON. Only the error bodies are JSON.
- **AuthorizationID, SubscriptionID and RetailCustomerID are the same value** at the customer level.

## Published rate limits

- 1 request per second per vendor, across all of that vendor's Client IDs
- 2,000 API calls per hour per Client ID
- 20,000 API calls per 24-hour period per Client ID, resetting at 5 p.m. PT
- No RateLimit-* or Retry-After response headers are documented.

## Events

PG&E POSTs an ESPI Notification (Green Button function block 39) to a notification URI you register,
after which you GET the corresponding `Batch/Bulk/{BulkID}` resource. The notification is not signed
and carries no delivery id; you must dedupe.

## What PG&E does not publish

- No OpenAPI, GraphQL, gRPC or WSDL contract
- No MCP server and no A2A agent card (all `/.well-known/` paths return 404 on every host)
- No `/.well-known/security.txt`, `openid-configuration`, `oauth-authorization-server` or `api-catalog`
- No developer status page, changelog, deprecation policy, SLA or CLI
- No public pricing for API access; fees, where any apply, follow CPUC tariff
